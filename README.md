# Mesa de Partes Digital (CIIN1205P)
Prototipo en Python para la Municipalidad de Chorrillos: registrar, validar, buscar (por código y por DNI), ordenar y guardar expedientes.

- Campos: DNI, nombre, tipo de trámite (catálogo cerrado), asunto y fecha.
- Ejecutar: `python main.py` | Pruebas: `python pruebas.py`
